# Built in libaries

## strtools.ro - string libary
### split
```
split(<text>, <letter>) # return the seperated list
```
### to_upper
```
to_upper(<text-ascii>) # return the upper letter of the english alphabet "abc" -> "ABC"
```
### to_lower
```
to_lower(<text-ascii>) # return the lower letter of the english alphabet "ABC" -> "abc"
```

### replace
```
reaplace(<text>, <old text>, <new text>) # return the replace in <text> <old text> to <new text>
```

## conv - convertion libary
### to_string
```
to_string(<data>) # returns the string of the data (char/int/float) 123 -> "123"
```

### to_char
```
to_char(<string with length 1>) # return the byte of the string
```

### to_int
```
to_int(<text>) # return the int version of the text "123" -> 123
```
